## 本轮：IR-11 纯 SSA 循环不变量外提

实现及测试入口见 [LICM 说明](ir-licm.md)。关键边界：

- 通过支配回边识别自然循环，合并同一 header 的多个 latch，先处理内层循环。
  仅使用既有、唯一、无条件 preheader，不创造新的 CFG 边，也不删除预算恢复点。
- 只允许无副作用、不会触发异常的标量/向量 SSA 运算；不移动 CPU 读取、访存、
  检查、helper、除法、SSE 守卫或带恢复/提交元数据的指令。
- 在副本中改写，前后验证 SSA；预算耗尽或验证失败不提交部分结果。
- 只接入优化 Tier 2。Tier 1、关闭优化、关闭 GVN 诊断开关或零轮配置不运行 LICM。
  `CompiledArtifact.passes.loop_hoisted` 记录外提次数；嵌套外提可能重复计数同一指令。
- 测试覆盖循环携带状态、依赖链、多个入口/latch、嵌套/自循环、预算回滚、拒绝规则，
  以及 CPU 编译入口和开关。Wasm 对照包含不同执行预算、零次循环、溢出和无效入口。

## 验收与默认切换

覆盖目录仍有 864 条编码、3,830 个粗粒度形式，其中 102 个明确 baseline-UD，
**3,728 个生产形式仍是 Pending**。本轮没有修改覆盖台账来制造完成率。
`make ir-default-gate` 在 Pending 非零时应继续失败。

CI 的 `IR core` 工作流从干净检出生成六张基线指令表，运行定向 LICM、Wasm 对照和
原有 Rust/Wasm 测试；另有 CPU Wasm 编译与在线运行时回归。以具体提交的实际 CI
结果判断通过情况；新增测试不等于完整系统验收。尚不能据此宣称 XP 兼容、游戏加载
改善或某个 CPU 性能提升比例。

后续仍需完成 ISA、MIR 图变换/分配调度、proof/链接/共享版本管理，并执行原计划的
系统及性能矩阵。全部门槛满足前，不切换默认后端，不移除 legacy。
